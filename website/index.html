Ubuntu 22.04 / 24.04 LTS / Debian

Install prerequisites and run the native installer:

./install.sh

Arch Linux / Manjaro

Install packages with pacman and compile:

sudo pacman -S --needed base-devel cmake qt6-base mpv
git clone https://github.com/abhinavsanthoshpp/orionplayer.git
cd orionplayer
./install.sh

Compile from Source (CMake)

Build using GCC 12+ or Clang and CMake 3.16+:

git clone https://github.com/abhinavsanthoshpp/orionplayer.git
cd orionplayer
mkdir build && cd build
cmake .. -DCMAKE_BUILD_TYPE=Release
make -j$(nproc)
./orionplayer

Speed Up with Keyboard Controls

Intuitive shortcuts for instant playback manipulation.

Shortcut Action Description
Space Play / Pause Instantly toggle playback anywhere
← / → Seek -10s / +10s Standard VLC 10-second skip forward/backward
Shift + ← / → Very Short Seek -3s / +3s Fine precision seek with on-screen OSD badge
Ctrl + ← / → Medium Seek -1m / +1m Jump 1 minute backward or forward
Ctrl + Alt + ← / → Long Seek -5m / +5m Jump 5 minutes backward or forward
↑ / ↓ Volume Adjust Increase or decrease volume by 5% (up to 200% VLC booster)
M Mute / Unmute Toggle audio mute with OSD HUD indicator
F / F11 Fullscreen Toggle Seamless immersive fullscreen mode
S Stop Stop playback and reset stream position
N / P Next / Previous Advance or return in playlist queue
E Frame Step Advance playback frame-by-frame
[ / ] Speed -0.1x / +0.1x Pitch-perfect playback speed adjustment (scaletempo2)
= / Backspace Normal Speed Reset speed to standard 1.00x
A Cycle Aspect Ratio Cycle Default → 16:9 → 4:3 → 1:1 → 16:10 → 2.35:1
